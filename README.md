# schoolnetwork.coop

Static school-owned media and cooperative economy website.

## GitHub Pages

Publish the main branch from the repository root in Settings → Pages → Deploy from a branch.

All assets use relative paths so the site supports a GitHub Pages project URL. No ChatGPT services, authentication, hosting configuration or credentials are required.

Enquiries use email links. The income calculator runs locally in the browser. The school pilot is a proposal, and live content subscriptions are not yet active.

Connect schoolnetwork.coop only after domain ownership and DNS configuration are confirmed.
